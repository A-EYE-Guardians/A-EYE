# Dual-Camera Iris Gaze v2 (Calib + Homography)

두 대의 카메라(월드/눈)와 MediaPipe FaceMesh(iris), OpenCV를 사용해 **시선 포인트를 월드 영상 위에 표시**하는 프로토타입입니다.  
본 버전은 다음을 포함합니다.

- ✅ **눈-내부 정규화 특징 (vx, vy)** 기반 **2차 다항 캘리브레이션**
- ✅ **ArUco 기반 월드 평면 정합(호모그래피)** → 실제 모니터/보드에 정확히 찍기
- ✅ EMA 스무딩, 디버그 HUD, 키보드 토글

> **주의**: 연구/제품 수준 정확도를 목표로 한다면 추가로 머리자세(Head Pose) 보정, 깜박임/이상치 마스킹, 더 정교한 필터(1-Euro/Kalman) 등이 필요합니다.

---

## 1) 설치

**Windows (권장)**

```powershell
# 1) 가상환경 생성/활성화
python -m venv venv
.\venv\Scripts\activate

# 2) 업그레이드 및 필수 설치
python -m pip install --upgrade pip

# 필수
pip install mediapipe opencv-python numpy

# (선택) ArUco 사용 시 필요
pip install opencv-contrib-python
```

> GPU 가속은 MediaPipe FaceMesh가 기본적으로 CPU 경로를 이용하므로 특별 설정이 필요 없습니다.

---

## 2) 실행

```bash
python dual_camera_iris_gaze_v2.py --world_cam 0 --eye_cam 1 --world_w 1280 --world_h 720 --eye_w 640 --eye_h 480 --flip_eye
```

- `--world_cam`, `--eye_cam` : OS에서 잡힌 카메라 인덱스입니다.
- `--flip_eye` : 노트북/웹캠 셀피처럼 좌우 반전이 필요할 때 사용하세요.
- `--ema_alpha` : 스무딩 강도(0.1~0.5 권장)
- `--calib_path` : 캘리브 계수 저장/로드 파일 경로 (default: `gaze_calib.npz`)

창이 2개 뜹니다.

- **World (Gaze Overlay)** : 월드 카메라 영상 + 시선 마커
- **Eye (Debug)** : 눈 카메라 영상(+디버그 원 옵션)

## 3) 조작키

- `q` : 종료
- `h` : 도움말 HUD 토글
- `d` : 눈 프레임 디버그(홍채 원) 토글
- `r` : EMA 스무딩 상태 리셋

### 캘리브레이션(화면 보정)

- `c` : **9-포인트 캘리브레이션 모드** 시작/종료
  - 모드 진입 시, 월드 창에 초록색 원이 나타납니다(정규좌표 타깃: `(0.1/0.5/0.9) × (0.1/0.5/0.9)`)
  - **각 점을 바라본 후 `SPACE`** 를 눌러 샘플을 채집하세요. 여러 번 눌러 평균화해도 됩니다.
  - 9점 완료 시 자동으로 2차 다항 회귀를 수행하고 **보정이 활성화**됩니다.
- `SPACE` : (캘리 모드일 때) 현재 프레임을 샘플로 채집
- `g` : **보정 on/off**
- `S` : 보정 계수 저장 (npz)
- `L` : 보정 계수 로드 (npz)

> 특징 벡터는 **iris 중심 대비 "눈 컨투어 bbox 중심"의 상대좌표 (vx, vy)** 로, 눈의 크기/기하를 기준으로 정규화되어 고개 미세 움직임/개인차에 상대적으로 강합니다.

### 월드 평면 정합(ArUco 호모그래피)

- `a` : ArUco 기반 호모그래피 on/off
  - **전제**: 모니터/보드의 **네 모서리에 ArUco 마커 4개**를 배치합니다.
    - ID **0** = 좌상(TL), **1** = 우상(TR), **2** = 우하(BR), **3** = 좌하(BL)
  - 카메라가 마커 4개를 동시에 인식하면, 화면 정규좌표 `(sx,sy)` 를 **월드 픽셀**로 투영하는 **H**를 추정/갱신합니다.
  - 라이브로 마커가 가려지면 새롭게 탐지될 때까지 이전 H가 유지됩니다.

> 마커 생성: OpenCV Python으로 DICT_4X4_50 사전에서 생성하거나, 온라인 생성기에서 ID 0~3을 출력/인쇄 후 코너에 부착하세요.

## 4) 동작 원리 (요약)

1. **FaceMesh (refine_landmarks=True)** 로 얼굴 랜드마크 + 홍채(iris) 포인트 추정
2. **눈 특징 (vx,vy)** = (iris 중심 − 눈 컨투어 bbox 중심) / (눈 폭/높이)
3. **캘리브레이션**: 9개 표적점의 화면 정규좌표(sx,sy) ↔ 특징(vx,vy)을 수집 →  
   2차 다항식 `sx=f(vx,vy)`, `sy=g(vx,vy)` 회귀 → 실시간 매핑에 사용
4. **월드 정합(선택)**: ArUco 4코너 검출 → 정규 스크린 좌표(0~1)^2 ↔ 월드 픽셀 좌표 간 **호모그래피 H** 추정 → 시선점을 월드 영상 위 정확한 위치에 표시

## 5) 트러블슈팅

- **Eye 창이 거꾸로/좌우가 반대**
  - `--flip_eye` 옵션을 켜보세요.
- **캘리브 후에도 오차가 큼**
  - 조명/포커스/안경 반사 등에 민감합니다. 9점에서 **여러 샘플을 반복 수집**해 평균화하세요.
  - `--ema_alpha`를 0.2~0.35 사이로 조절해보세요.
- **ArUco가 인식 안 됨**
  - `pip install opencv-contrib-python` 설치 여부 확인
  - 마커가 충분히 크고 선명한지, 네 개가 모두 프레임에 보이는지 확인
  - TL(0), TR(1), BR(2), BL(3) **ID 배치 순서**가 맞는지 확인
- **프레임레이트가 낮음**
  - `eye_w/eye_h`를 작게, `world_w/world_h`도 적절히 조정하세요.
